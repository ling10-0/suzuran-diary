翻閱1938：那些待續的章節｜最終單機封存版
=======================================

用途
----
此版本提供主管、後續實習生與成果保存使用。
內容以目前正式網站為準，遊戲本體可在 Windows 電腦上離線執行，不需要安裝 Node.js、VS Code 或另外設定資料庫。

啟動方式
--------
1. 請先把 ZIP「完整解壓縮」到一般資料夾。
2. 雙擊「啟動遊戲.bat」。
3. 系統會開啟一個命令視窗，並使用電腦平常的預設瀏覽器開啟遊戲分頁。
4. 單機版使用獨立的本機回環網址 127.0.0.2，避免沿用過去 127.0.0.1 的瀏覽器縮放設定。
5. 遊戲版面、字級、卡片與互動直接沿用正式網站，不使用另外的 App 視窗縮放。
6. 第一次開啟會從姓名登記與選組開始，之後可完整參考原本遊戲流程。
7. 遊戲期間請保留命令視窗開啟；玩完後關閉該視窗即可停止本機伺服器。

資料與正式活動隔離
------------------
- 單機展示版會自動進入離線隔離環境。
- 姓名登記、正式三組或「測試／觀賞模式」在此版本中都只使用本機資料。
- 遊戲進度只保存在目前瀏覽器與這台電腦。
- 不會讀寫正式活動的 Supabase 共同進度。
- 右下角只保留縮小的「單機版／重置體驗」工具。
- 離線版不提供退出到正式模式的按鈕，避免誤改正式資料。

網路需求
--------
遊戲主要內容、圖片、題目、劇情與地點標記皆包含在單機包內。
離線版的地圖底圖會改用內建示意底圖，因此不需要 OpenStreetMap 網路服務。
若點擊「Google Maps 導航」或官方 Instagram／Threads／Facebook 等外部連結，該連結本身仍需要網路，這不影響遊戲流程。

如果雙擊後沒有打開
------------------
- 請確認 ZIP 已完整解壓縮，不要直接在壓縮檔預覽畫面內執行。
- Windows 若詢問是否允許執行 PowerShell，請允許本機腳本執行。
- 若 1938 連接埠被占用，啟動器會自動嘗試 1939–1948。
- 若被公司電腦的資訊安全政策禁止 PowerShell，請請資訊人員協助。
- 若瀏覽器仍曾自行調整 127.0.0.2 的縮放比例，可按 Ctrl + 0 恢復為 100%。

成果保存建議
------------
請保存整個 ZIP 原檔，不要只留下 index.html。
完整 ZIP 才包含遊戲程式、圖片素材、本機啟動器與相關資源。
建議將「翻閱1938_最終單機封存版_Windows.zip」上傳至單位 Google Drive／雲端硬碟，作為最終交付檔。
