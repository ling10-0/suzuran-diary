翻閱1938：那些待續的章節｜Windows + Mac 最終單機封存版
====================================================

用途
----
此版本提供主管、後續實習生與成果保存使用。
內容以目前正式網站為準，遊戲本體可在 Windows 或 Mac 電腦上離線執行，不需要安裝 Node.js、VS Code 或另外設定資料庫。

Windows 啟動方式
----------------
1. 請先把 ZIP「完整解壓縮」到一般資料夾。
2. 雙擊「啟動遊戲.bat」。
3. 系統會開啟命令視窗，並使用預設瀏覽器開啟遊戲。
4. Windows 使用 127.0.0.2 的本機回環網址，避免沿用之前 127.0.0.1 的瀏覽器縮放紀錄。
5. 遊戲期間請保留命令視窗開啟；玩完後關閉即可停止本機伺服器。

Mac 啟動方式
------------
1. 請先把 ZIP「完整解壓縮」到一般資料夾。
2. 雙擊「啟動遊戲_Mac.command」。
3. 系統會開啟 Terminal，並使用預設瀏覽器開啟遊戲。
4. Mac 使用標準 127.0.0.1 本機回環網址。
5. 遊戲期間請保留 Terminal 視窗開啟；玩完後關閉即可停止本機伺服器。
6. 若 macOS 第一次阻擋執行，請在 Finder 對「啟動遊戲_Mac.command」按右鍵 →「打開」→ 再確認「打開」。之後即可正常雙擊使用。

共同體驗
--------
- 本機回環網址只在目前這台電腦運作，不會連到 GitHub 網站。
- 遊戲版面、字級、卡片與互動直接沿用正式網站。
- 圖片、題目、劇情與主要遊戲素材均包含在 ZIP 內。
- 中央書局的匿名文章、退稿紀錄與最後殘頁等圖片會直接從本機 assets 讀取。

資料與正式活動隔離
------------------
- 單機展示版會自動進入離線隔離環境。
- 姓名登記、正式三組或「測試／觀賞模式」在此版本中都只使用本機資料。
- 遊戲進度只保存在目前瀏覽器與這台電腦。
- 不會讀寫正式活動的 Supabase 共同進度。
- 右下角保留縮小的「單機版／重置體驗」工具。
- 離線版不提供退出到正式模式的按鈕，避免誤改正式資料。

網路需求
--------
遊戲主要內容、圖片、題目、劇情與地點標記皆包含在單機包內。
離線版的地圖底圖會改用內建示意底圖，因此不需要 OpenStreetMap 網路服務。
若點擊「Google Maps 導航」或官方 Instagram／Threads／Facebook 等外部連結，該連結本身仍需要網路，這不影響主遊戲流程。

如果無法啟動
------------
Windows：
- 請確認 ZIP 已完整解壓縮，不要直接在壓縮檔預覽畫面內執行。
- Windows 若詢問是否允許執行 PowerShell，請允許本機腳本執行。
- 若公司電腦的資訊安全政策禁止 PowerShell，請請資訊人員協助。

Mac：
- 請確認 ZIP 已完整解壓縮，不要直接在壓縮檔內執行。
- 第一次若被 macOS 阻擋，請使用 Finder 右鍵 →「打開」。
- 封存包內含 Intel Mac 與 Apple Silicon 都可使用的通用 macOS 本機伺服器，不需要另外安裝 Python 或 Node.js。

共同：
- 1938 連接埠若被占用，啟動器會自動嘗試 1939–1948。
- 若瀏覽器縮放比例被調整，Windows 可按 Ctrl + 0；Mac 可按 Command + 0 恢復為 100%。

成果保存建議
------------
請保存整個 ZIP 原檔，不要只留下 index.html。
完整 ZIP 才包含遊戲程式、圖片素材、Windows／Mac 本機啟動器與相關資源。
建議將「翻閱1938_最終單機封存版_Windows_Mac.zip」上傳至單位 Google Drive／雲端硬碟，作為最終交付檔。
